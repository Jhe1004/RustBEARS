# Changes

## 1.2.0 development

- Add explicit root distributions and likelihood contracts for tip survival,
  a completed unconditional process, and historical scoring compatibility.
- Add reusable native simulation and mapping contexts shared by R and Python.
- Add nuisance-optimized profile intervals, parameter surfaces, and a
  parametric bootstrap that records retries and incomplete-fit uncertainty.
- Add contract-checked model averages and external-tree summaries with clade
  matching, cold-start audits, missing-tree bounds, and complete checkpoints.
- Add mapping precision diagnostics for fixed trees, stratified model weights,
  and independent or correlated external tree samples.
- Freeze logical random-task identities across workers and frontend languages.
- Add installed-package tests, a three-platform CI definition, bilingual
  tutorials, an R vignette, empirical workflow runners, and calibration scripts.
- Preserve a tagged 1.1.4 baseline and compare legacy mapping streams directly.

Stable-release approval still requires the AMD cost pilot, actual three-platform
CI results, formal calibration, empirical analyses, and the final archive audit.
The development version does not imply that these release gates have passed.
